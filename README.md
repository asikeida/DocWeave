# DocWeave

DocWeave 是一个面向个人知识管理的智能文档知识库。它让用户上传资料、构建知识库、检索原文，并在问答中保留可回溯的引用证据。

项目将作为可在线访问的求职作品持续迭代。当前处于工程骨架阶段，优先建立稳定的配置、数据库演进、接口文档、日志、测试和部署基础。

## 当前技术基线

- Java 21
- Spring Boot 4.1.1
- Maven Wrapper
- Spring Data JPA
- MySQL
- Flyway
- Bean Validation
- Spring Boot Actuator
- OpenAPI / Swagger UI

前端采用 Vue 3、TypeScript 和 Vite，位于 `frontend/` 目录，目前提供概览、404 和健康连接验证。前后端独立构建与部署，但由同一个 Git 仓库管理。

## 计划功能

1. 账号、登录和工作空间
2. 知识库与文档管理
3. 文档解析、切分和异步处理
4. 检索、索引和权限过滤
5. 基于引用证据的智能问答
6. 对话历史、引用预览和在线演示

完整路线见 [项目骨架与模块开发路线](docs/开发规划/01-项目骨架与模块开发路线.md)。
接口约定见 [接口设计约定](docs/接口说明/01-接口设计约定.md)。日志配置与查询见 [日志与请求追踪](docs/部署运维/02-日志与请求追踪.md)。

## 文档规则

- 长期有效的设计、接口、部署和决策文档放在 `docs/` 并提交。
- 临时分析、调试记录和未整理的 AI 草稿放在 `.local/`，不会提交。
- 不在仓库中保存密码、令牌、私钥、生产服务器地址或其他敏感信息。

## 开发方式

自动构建流程见 [后端自动构建与测试](docs/部署运维/03-后端自动构建与测试.md)（运行结果以 GitHub Actions 为准）。

- 每个任务从最新 `main` 创建短期分支。
- 每个提交只处理一个清晰目标。
- 合并到 `main` 前应通过与改动匹配的测试和构建验证。
- 详细协作规则见 [AGENTS.md](AGENTS.md)。
