# DocWeave

DocWeave 是一个面向个人知识管理的智能文档知识库。它让用户上传资料、构建知识库、检索原文，并在问答中保留可回溯的引用证据。

项目将作为可在线访问的求职作品持续迭代。当前处于工程骨架阶段，优先建立稳定的配置、数据库演进、接口文档、日志、测试和部署基础。

## 当前技术基线

- Java 21
- Spring Boot 4.1.1
- Maven Wrapper
- Spring Data JPA
- MySQL
- Bean Validation
- Spring Boot Actuator

前端计划采用 Vue 3、TypeScript 和 Vite，并位于 `frontend/` 目录。前后端独立构建与部署，但由同一个 Git 仓库管理。

## 计划功能

1. 账号、登录和工作空间
2. 知识库与文档管理
3. 文档解析、切分和异步处理
4. 检索、索引和权限过滤
5. 基于引用证据的智能问答
6. 对话历史、引用预览和在线演示

完整路线见 [项目骨架与模块开发路线](docs/开发规划/01-项目骨架与模块开发路线.md)。

## 目录说明

```text
DocWeave/
├─ src/                 # Spring Boot 后端
├─ frontend/            # Vue 前端（后续初始化）
├─ docs/                # 可提交的正式项目文档
├─ deploy/              # 容器和部署配置（后续建立）
├─ .local/              # 本地笔记和临时记录，不提交 Git
├─ AGENTS.md            # AI 与开发协作约定
├─ pom.xml
└─ compose.yaml         # 本地 MySQL
```

本地 MySQL、环境变量和测试运行方式见[本地开发环境](docs/部署运维/01-本地开发环境.md)。

## 文档规则

- 长期有效的设计、接口、部署和决策文档放在 `docs/` 并提交。
- 临时分析、调试记录和未整理的 AI 草稿放在 `.local/`，不会提交。
- 不在仓库中保存密码、令牌、私钥、生产服务器地址或其他敏感信息。

## 开发方式

- 每个任务从最新 `main` 创建短期分支。
- 每个提交只处理一个清晰目标。
- 合并到 `main` 前应通过与改动匹配的测试和构建验证。
- 详细协作规则见 [AGENTS.md](AGENTS.md)。
