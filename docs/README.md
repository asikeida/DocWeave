# DocWeave 文档目录

`docs/` 只存放经过整理、适合长期维护并提交到 Git 的项目文档。

## 目录约定

| 目录 | 内容 | 是否提交 |
| --- | --- | --- |
| `开发规划/` | 阶段目标、范围和交付顺序 | 是 |
| `架构设计/` | 系统结构、数据模型、RAG 链路 | 是 |
| `接口说明/` | API 约定、鉴权和集成说明 | 是 |
| `部署运维/` | 本地环境、上线、监控和故障处理 | 是 |
| `决策记录/` | 重要技术选择及其原因 | 是 |
| `assets/` | 架构图、截图和文档素材 | 是 |

文件以两位数字开头，方便按阅读顺序排列，例如：

```text
01-系统上下文与组件边界.md
02-数据模型.md
```

## 不提交的内容

以下内容放在仓库根目录 `.local/`，该目录已被 Git 忽略：

- AI 对话原稿和未经整理的分析
- 临时排查记录、请求响应样本和运行日志
- 个人待办和实验性方案
- 本机环境中的非敏感临时文件

涉及密码、令牌、私钥、生产主机信息或其他敏感数据的内容，不应写入 `docs/` 或 `.local/`。这些内容只保存在受控的本地环境或部署平台中。

如果一份本地笔记沉淀出长期价值，应整理、脱敏后移入对应的 `docs/` 子目录。

AI Agent 的工作规则不属于项目文档，统一维护在仓库根目录 [`.agents/rules/`](../.agents/rules/README.md)。
