# 本地开发环境

本项目后端需要 Java 21、Maven Wrapper 和 Docker Desktop。Docker 仅运行本地 MySQL；Spring Boot 从 IDE 或命令行启动。

## 1. 准备配置

复制根目录的示例文件为 `.env`，再替换其中的本地数据库密码：

```powershell
Copy-Item .env.example .env
```

`.env` 被 Git 忽略，禁止提交。该文件供 Docker Compose 读取；Spring Boot 不会自动读取它。

## 2. 启动 MySQL

确认 Docker Desktop 已启动后，在项目根目录执行：

```powershell
docker compose up -d
docker compose ps
```

MySQL 会以 named volume `mysql-data` 保存数据。需要停止容器时执行：

```powershell
docker compose down
```

## 3. 启动后端

在 IntelliJ 的运行配置中选择 JDK 21，并设置以下环境变量；值与 `.env` 中相同：

```text
DOCWEAVE_DB_NAME=docweave
DOCWEAVE_DB_USERNAME=docweave
DOCWEAVE_DB_PASSWORD=<本地数据库密码>
DOCWEAVE_DB_HOST=localhost
DOCWEAVE_DB_PORT=3306
```

然后运行 `DocWeaveApplication`。默认使用 `local` profile，连接本地 MySQL。Flyway 会在启动时执行已提交的迁移；JPA 只校验结构，不会建表或改表。

## 4. 运行测试

测试使用 `test` profile 和内存 H2，不需要 Docker 或本地 MySQL。确认终端使用 Java 21 后执行：

```powershell
.\mvnw.cmd test
```

若本机的 `java -version` 仍显示 Java 8，请先在终端或 IDE 中切换到已安装的 JDK 21，再运行 Maven。Spring Boot 4.1.1 最低要求 Java 17，本项目固定使用 Java 21。

## 5. 数据库迁移约定

首个需要持久化的业务模块提交时，在 `src/main/resources/db/migration/` 中新增 `V1__<英文说明>.sql`。同一个交付中的实体、Repository 与迁移必须一起评审和验证。
