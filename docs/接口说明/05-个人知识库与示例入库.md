# 个人知识库与示例入库（Issue #17）

当前分支提供个人示例库、两份独立文档与首版正文快照，以及列表/详情。已入库不等于已解析或已索引，所有知识库和文档均显示NOT_INDEXED，不能问答。企业知识库、INHERIT/RESTRICTED授权、上传、编辑、删除和恢复尚未开放。

## 迁移与旧版本兼容

追加V3，不修改V1/V2。新建knowledge_bases、documents、document_versions；复合外键约束资源属于同一组织。正文为小型虚构示例的数据库TEXT快照，不预建MinIO或通用文件存储框架。未来大文件上传需独立对象存储方案，不把本实现当成大文件存储设计。

旧personal_sample_initializations.state的WAITING_FEATURE约束保留，新增import_state=PENDING/IMPORTED_NOT_INDEXED，原有记录默认回填PENDING，并增加尝试次数、安全错误码和重试时间。应用对外sampleState改从import_state读取。旧账号不丢待办，新注册也在个人区域事务中创建PENDING待办。

V3增加列后，旧版无列名的INSERT不兼容。当前代码已改显式列名；部署前备份并停止旧写入进程，不可直接退回V2版本继续注册写库，也不可修改Flyway历史回滚。本轮只在新隔离审核库执行V3，未升级原共享开发库和旧审核库。

## 初始化

后台每30秒取最多10个到期PENDING待办，默认启用；docweave.samples.worker-enabled=false可关闭，poll-delay-ms控制轮询周期。每个账号的初始化是独立事务，先锁ACTIVE用户行，再核验个人区域、锁待办；只有PENDING/v1才复制两份模板并一次提交库/文档/首版本及完成状态。重复、并发或多实例消费者不会重复建库。测试环境明确关闭定时任务，避免断言与后台并发。

失败后主事务回滚，待办保留PENDING。后台另记录attempt_count、last_error_code=SAMPLE_IMPORT_FAILED及60秒后重试；每项自动最多5次，之后需手动重试。恢复和重启不依赖内存任务。数据库整体不可用时错误记录也无法落库，待数据库恢复后再取持久化待办；没有声称所有故障都能实时持久化。

已完成记录不回退；文档/库即使标记deleted，重试初始化也不恢复，不覆盖版本快照。删除和显式恢复API不属于本轮。未来模板v2需单独策略，当前仅消费v1，不静默覆盖已有内容。

## API

均需Bearer；POST还需先GET csrf并带同一Cookie及X-XSRF-TOKEN。均no-store并带requestId。客户端不提供目标用户或组织，授权从当前身份和真实成员/空间直接授权推导。

| 方法 | 路径 | 返回 |
| --- | --- | --- |
| POST | /api/v1/personal-area/sample-import | 幂等初始化，200知识库数组 |
| GET | /api/v1/knowledge-bases | 本人授权知识库数组 |
| GET | /api/v1/knowledge-bases/{id} | 一个知识库元数据 |
| GET | /api/v1/knowledge-bases/{id}/documents | 授权库内文档摘要数组 |
| GET | /api/v1/documents/{id} | 文档摘要及自己的正文快照 |

KnowledgeBase含id/name/workspaceId/documentCount/state；DocumentSummary含id/knowledgeBaseId/title/sampleKey/seedVersion/sha256/indexState；DocumentDetail含document/content。版本v1来自模板来源，不代表用户文档ID；不同用户的库、文档和版本ID均独立。正文响应toString省略内容。

未登录401，CSRF失败403，未知/跨组织/已删除资源404，不泄漏它们是否存在。原个人区域失效仍为PERSONAL_AREA_UNAVAILABLE/404。未知模板待办版本503；其他数据库或系统故障按既有安全异常处理，不统一伪装成功。初始化数据库约束冲突不应返回空列表假成功。
