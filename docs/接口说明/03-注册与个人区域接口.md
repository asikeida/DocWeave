# 注册与个人区域接口（Issue #15）

> Issue #17 更新：个人示例可独立入库，区域状态使用 PENDING/IMPORTED_NOT_INDEXED；模板预览本身仍是只读原文，不代表索引就绪。最新契约见 [个人知识库与示例入库](05-个人知识库与示例入库.md)。下文的旧阶段说明以该更新为准。


当前分支实现账号注册、个人区域创建/查询/历史账号幂等补建。问答、知识库、文档上传和示例导入尚未实现，sampleState固定为WAITING_FEATURE，不表示READY。

## 启用与安全

注册默认关闭，仅local/test并显式设置DOCWEAVE_REGISTRATION_ENABLED=true时开放。Spring宽松绑定可将该环境变量映射docweave.registration.enabled。即使local和prod同时激活也拒绝注册。每个来源地址一小时最多5次尝试（含失败），单实例最多4096个活动地址窗口；返回429和Retry-After:3600。重启清空本机计数，多实例部署需共享限流与配额，当前不可直接作为公网注册系统。

数据库和JWT仍使用原运行方式。不要对原共享开发库直接运行本分支：启动会应用V2，先备份并审核。本轮仅创建新的隔离审核库，配置位于忽略文件.env.onboarding-review。

## 调用顺序

先GET /api/v1/auth/csrf，保留同一Cookie会话，将返回token放入X-XSRF-TOKEN；POST注册成功后再POST既有login，使用返回的Bearer查询个人区域。注册不自动登录，不写刷新Cookie。

| 方法与地址 | 鉴权/请求 | 响应 |
| --- | --- | --- |
| POST /api/v1/auth/register | CSRF；JSON username,password,displayName | 201 PersonalArea |
| GET /api/v1/personal-area | Bearer，无请求体 | 200 PersonalArea；不存在或不可用404 |
| POST /api/v1/personal-area/initialize | Bearer+CSRF，无请求体 | 200同一个PersonalArea；停用或缺授权不自动恢复 |

PersonalArea字段为organizationId、workspaceId、name、sampleState。不能传目标userId或角色来选择他人的区域；读取只使用认证身份，额外查询参数不会授权访问他人数据。当前没有按ID读取空间接口，不提供空壳路由。

错误复用ApiError和X-Request-Id：400字段/密码字节限制，401身份失效，403注册关闭或CSRF失败，409账号不可用，429限流；未知异常安全返回500。数据源不可用在Bearer身份核验环节为503；注册/初始化持久化异常不一概保证503。账号冲突响应不区分停用状态。

账号3～64位ASCII字母/数字/点/下划线/连字符且首位字母或数字，规范为小写；密码至少12字符且UTF-8最多72字节；显示名非空不超过80字符。请求类型toString与OpenAPI隐藏密码，不把响应Entity直接暴露。

## 数据与事务

追加V2而不修改V1。organizations保存个人组织及唯一owner_user_id；organization_memberships对个人组织限本人OWNER；workspaces为每个人建立唯一默认空间；workspace_grants建立直接ADMIN。复合外键阻止跨组织成员与空间引用；成员资格仍需ACTIVE，创建者不是权限旁路。

personal_sample_initializations与organization_events随同一次事务写入。初始化待办固定v1/WAITING_FEATURE，无消费者、不解析、不调模型；没有凭空建立知识库和文档表。企业成员/邀请/部门没有提前实现，后续迁移需扩展当前仅个人组织的关系约束。

用户持久化沿用JPA；个人区域使用集中在Repository的参数化JdbcTemplate，明确表达多表原子写入、复合约束及授权查询。两者参加同一Spring数据库事务，测试验证回滚。没有为只在这个用例使用的每张关系表额外生成无行为实体。

历史账号initialize先锁定ACTIVE用户行，再检查是否存在组织；并发补建串行，存在但停用或缺少授权时不重建或重新激活。GET不执行补建。未实现的示例删除/恢复按产品设计在后续阶段交付。

## 前端

/register提供最小注册表单；成功后引导登录；登录后跳转/personal。历史受控账号可点击初始化。两份虚构资料只显示预告，不能上传或问答。/account保留。生产不应以当前开发界面宣传完整个人试用。
