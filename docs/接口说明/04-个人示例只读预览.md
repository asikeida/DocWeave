# 个人示例只读预览

Issue #16。两份虚构资料现在可在本人个人区域中阅读原文，仍未导入个人知识库或索引，不能问答。预览共享只读模板字节；未来个人文档记录、删除、恢复和聊天仍须按用户独立持久化。

## 接口

- GET /api/v1/personal-area/samples：Bearer；返回两份Summary的数组。
- GET /api/v1/personal-area/samples/{sampleId}：Bearer；返回sample元数据、format=plain-text和content。

Summary含id/title/version/sha256/readyForChat/suggestedQuestions。readyForChat固定false；SHA256对UTF-8正文统一LF后计算，Windows/Linux一致。ID只能为employee-handbook、travel-expenses，不允许拼接用户文件路径。

匿名401；本人区域未建、成员停用或直接授权不可用404；未知模板404；数据库身份核验失败按既有安全处理返回。响应no-store并保留X-Request-Id。不接受tenantId/userId切换目标，不能把前端隐藏当权限检查。

服务启动时从classpath加载固定两份原文；资源缺失启动失败，避免伪装成空文件成功。唯一维护源为src/main/resources/samples/v1/*.md，原产品文档路径改为链接，不维护两份容易漂移的正文。

前端仅文本插值和pre换行，不使用v-html，也不执行Markdown内嵌HTML。显示推荐问题但无AI作答按钮。切换身份、重新加载区域或离开页面时清空预览并取消请求。

本轮未修改数据库迁移、初始化WAITING_FEATURE或注册开关；没有创建个人文档/解析/索引任务。尚无上传、删除、恢复和RAG。
